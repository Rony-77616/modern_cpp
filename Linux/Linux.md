# 1.Linux的优点
Linux的主要优势体现在服务器、网络编程和系统开发上。
- 开发环境和服务器接近：网站后端、聊天服务、游戏服务器等，很多部署在linux上。
- 学习程序和操作系统怎样配合
- 排查问题工具丰富
- 容易把重复操作自动化



# 2.Linux常用命令

- 查看当前目录： pwd   查看当前正在哪个文件夹里操作
- 查看目录里的内容： ls  显示当前目录里的文件和文件夹。加上不同参数可以改变显示方式： -l，显示详细信息      -a，同时显示显示隐藏文件，linux中名称以.开头的文件或文件夹通常是隐藏的。
- 切换当前目录 cd  回到自己的用户主目录：cd ~      进入当下目录的文件夹： cd 文件夹名称     返回上一级的目录： cd..
