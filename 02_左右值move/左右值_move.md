# 一.什么是左值和右值
## 1.左值（Lvalue）
- 具有地址，存储在内存中
- 可以出现在 = 赋值号的左侧
- 可以取地址 & 
- 变量 对象 数组元素 字符串 都是左值。
  
## 2.右值
- 通常没有地址，存储在寄存器或临时内存中
- 不能出现在 = 的左侧
- 通常没有地址，不能取地址（除非绑定到const左值引用）
- 字面量 表达式计算结果都是右值
  
## 3.左值引用
```cpp
    int a = 10;
    int& b = a;
    b = 20; //引用是变量的别名，是通过指针实现的。
            //修改b相当于修改了a的值
```

- 左值引用在声明时必须初始化，且不能修改绑定的对象。
- 只能绑定到左值，普通左值引用不能绑定普通右值
- const左值引用可以绑定到左值和右值
- 左值引用主要用于别名 修改对象和避免拷贝
- 非常量引用的初始化，必须用一个左值来初始化。

## 4.右值引用
```cpp
    int a = 10;
    int&& b = a;//b是右值引用，但表达式b是一个左值，有名字，可以取地址。
```
- 右值引用可以绑定右值，但不能绑定普通左值。


### 5.move移动语义
- move是一种用于节省空间，“移交资源所有权”的机制，用于避免昂贵的赋值
- move返回的是指向原对象的右值引用，他把原对象转换成一个将亡值，不创建临时对象，也不复制原对象的内容。
- move后原本的对象的内容不改变，但是原本的内容不再依赖原本的对象，已经被转移给了新的对象（不同类型有不同移交管理权的方式，例如socket编号，数据库链接句柄等等），原本对象的内容可以改，也不影响内容，因为已经被转移了。
- move返回右值引用，是让编译器在重载时选择“移动版本”，或者直接出发移动构造，相当于新对象有一个指针指向这块内存，而原本的对象不再指向这块内存。
- 新对象通过“接收右值引用参数的构造函数”来接收它，也就是移动构造函数。之所以要转换成右值引用而不转换成其他的引用类型，是因为c++的重载规则本来就会根据参数的左右值类型来选择不同函数，而引用正好能把这两类参数分开接收。 const &可以接左值也可以接收右值， &&只接受右值。而如果只用普通函数参数区分，她不能区分传进来的是左值还是右值，都可以接受，因此我们就需要传右值来区分是移动语义还是复制语义。const&常量左值引用可以接收左值和右值，而右值引用只能接收右值（根据协议优先级，传入右值优先选），所以可以区分。  许多类型内部使用一个左值常量引用和一个右值引用来区分，传入左值就重载左值引用，传入右值就用右值引用重载，来区分是赋值还是移动！！！！！
